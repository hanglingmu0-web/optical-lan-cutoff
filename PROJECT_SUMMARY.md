# Project Summary

Optical LAN Cutoff is an experimental defensive security prototype combining decoy detection, Arduino-based optical notifications, LAN switch power control, and report logging on a separate Windows PC.

The November 1, 2026 integration tests exercised six simulated detection categories. Automatic notifications were verified at the transmitter, and the receiver recorded six new optical emergency events. Its cutoff state remained latched while reporting continued; the evaluated receiver-log period contained 53 reports across the six categories.

Software checks comprised 16 passing decoy and notification tests and 16 separate passing Windows receiver self-tests.

This repository introduces the system, presents the hardware prototype, and summarizes the observed results within their experimental scope.
